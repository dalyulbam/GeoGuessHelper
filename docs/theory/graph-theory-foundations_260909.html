2.1 그래프 · 차수 · 인접행렬

2.2 경로 · 연결요소 · union-find

정의 2 · 경로와 연결요소 a 에서 b 로의 경로는 인접한 노드의 열 a = v0, v1, …, vk = b. "경로가 있다"는 V 위의 동치관계이고 그 동치류가 연결요소(connected component)다. union-find는 각 노드의 대표(parent)를 두고 find(x)(대표까지 올라가며 경로 압축)와 union(a,b)(두 대표를 잇기)로 동치류를 점진적으로 만든다 — 엣지를 하나씩 넣어도 요소가 유지된다.

G1의 연결요소는 둘: {A,B,C,D,E} 와 {F}. A 에서 E 로는 A–C–D–E 가 경로다. 만족하지 않는 예: F 에서 F 자신을 뺀 다른 어떤 노드로도 경로가 없다 — 차수 0 노드는 홀로 한 요소다 (survey §각도3 "구조적 고립 = 유일 단서"의 정의적 근거).

근중복 묶음(observe.py _dup_groups)의 손계산. 거리 < τ 인 쌍이 (a1,a2 · 0.08), (a2,a3 · 0.09), (a5,a6 · 0.07) 셋이라 하자. 노드는 쌍의 끝점, 엣지는 쌍이다.

2.3 클리크 · 극대 클리크

정의 3 · 클리크 K ⊆ V 가 클리크라 함은 K 의 모든 쌍이 인접함. K 가 극대(maximal)라 함은 어떤 노드를 더해도 클리크가 아님. 최대(maximum) 클리크는 크기가 가장 큰 것 — 극대와 다르다. 분자 = 크기 ≥ min_size 인 극대 클리크(molecule-theory 정의 3, 이 문서는 그 정의를 그대로 쓴다).

G1의 극대 클리크는 넷: {A,B,C}, {C,D}, {D,E}, {F} (networkx.find_cliques 출력을 정렬). min_size 3 이면 {A,B,C} 하나가 분자. 만족하지 않는 예 둘: {A,B} 는 클리크지만 C 를 더할 수 있으니 극대가 아니다. {A,B,C,D} 는 A–D·B–D 가 없어 클리크가 아니다 — D 는 C 와만 인접한 near-miss(molecule-theory §3.3, atom-observatory Q11 "분자 D 가 빠진 이유"). molecule-theory 의 검증 콜아웃("둘 중 어느 경우에도 {A,B,C,D}는 분자가 아니다")이 여기서 숫자로 확인된다.

K 클리크 ⇔ ∀ a,b ∈ K, a≠b : {a,b} ∈ E  ·  극대 ⇔ ∀ v ∉ K : K ∪ {v} 는 클리크 아님  ·  분자 = {K 극대 : |K| ≥ min_size}
출처: Bron–Kerbosch 1973(§5 #8) — 열거 알고리즘, networkx find_cliques 가 피벗 변형 구현 · 극대 클리크 수는 최악의 경우 지수적: survey §구현함 "20-파트 완전 다부 그래프에서 320 재현"(codex 감사) → molecule.py MAX_CLIQUES 200,000 · MAX_CLIQUE_SECONDS 60(L277~278) · 검사: "극대 클리크", "min_size 3", "{A,B,C,D} 는 클리크 아님"

2.4 단체 복합체 · Vietoris–Rips 복합체

정의 4 · 단체 복합체 유한집합 V 위의 단체 복합체 K 는 V 의 부분집합들의 모임으로, 부분집합에 닫혀 있다(σ ∈ K, τ ⊆ σ ⇒ τ ∈ K). 원소 σ 를 |σ|−1 차원 단체(simplex)라 한다(점 0, 변 1, 삼각형 2, 사면체 3). 점집합 X 와 ε 에 대해 Vietoris–Rips 복합체 VRε(X) 는 "모든 쌍이 ε 이내인 부분집합 전부"다 — 즉 ε-근접 그래프 Gε 의 클리크 전부를 단체로 갖는 클리크 복합체. 그러므로 VRε 의 극대 단체 = Gε 의 극대 클리크(molecule-theory §2.1).

G1을 클리크 복합체로 보면 0-단체 6(노드), 1-단체 5(엣지), 2-단체 1({A,B,C}). 오일러 표수 χ = 6 − 5 + 1 = 2, 그리고 χ = β0 − β1 (β0 = 연결요소 수 2, β1 = 독립 구멍 수)이므로 β1 = 0 — 삼각형이 채워져 구멍이 없다. 만족하지 않는 예: 같은 다섯 엣지를 그래프(1-복합체)로만 보면 χ = 6 − 5 = 1, β1 = 1 — A–B–C 가 구멍으로 남는다. molecule-theory 의 은유("채워짐이 개념의 존재")가 β1 하나의 차이다. 부분집합 닫힘의 반례: {A,B,C} 가 있는데 {A,B} 가 없는 모임은 복합체가 아니다.

VRε(X) = { σ ⊆ X : ∀ a,b ∈ σ, d(a,b) ≤ ε }  ·  χ(K) = Σk (−1)k·(k-단체 수) = Σk (−1)k βk
출처: Vietoris 1927(§5 #3) 원 구성 · Rips(미출판, 1970~80년대) → Gromov 1987(§5 #12)이 쌍곡군 연구에 사용 · "Vietoris–Rips" 명칭과 역사: Adamaszek–Adams, Pacific J. Math. 290(1) 2017 §1 msp.org/pjm/2017/290-1/… · 검사: "오일러 표수"

2.5 코사인 거리 · 자카드 유사도

정의 5 · 두 거리 벡터 u, v 의 코사인 유사도는 cos(u,v) = ⟨u,v⟩ / (‖u‖‖v‖), 코사인 거리는 d = 1 − cos ∈ [0, 2]. 단위벡터로 정규화하면 d = 1 − ⟨û,v̂⟩ = ‖û − v̂‖²/2 — 그래서 코드는 정규화 뒤 행렬곱 하나로 전 쌍 거리를 얻는다(정의 1, molecule-theory). 집합 A, B 의 자카드 유사도는 J = |A∩B| / |A∪B| ∈ [0, 1].

3차원 예. u = (1,2,2), v = (2,1,2), w = (2,−2,1) — 셋 다 ‖·‖ = 3. ⟨u,v⟩ = 2+2+4 = 8 → cos 8/9 → d(u,v) = 1/9 = 0.1111. ⟨u,w⟩ = 2−4+2 = 0 → 직교 → d(u,w) = 1.0(만족하지 않는 예: "가깝다"의 반대). ⟨v,w⟩ = 4−2+2 = 4 → d(v,w) = 5/9 = 0.5556. 항등식 확인: ‖û−v̂‖²/2 = 0.1111 ✓. 프로젝트 실측 분포(molecule-theory §다음): 평균 0.739 · p1 0.380 · p5 0.506 · p50 0.754 — 이 예의 0.111 은 실제 원자 쌍에서는 근중복(τ 0.10 근방) 수준이다.

2.6 상호 k-NN 그래프 · 백분위 임계 ε = Qx(d)

정의 6 · 두 개의 게이트 Nk(a) 를 a 의 k 최근접 노드 집합이라 하면 상호 kNN 엣지 {a,b} 는 b ∈ Nk(a) 이고 a ∈ Nk(b) 일 때만 있다. 백분위 임계 ε = Qx(d) 는 전 쌍 거리의 x-백분위수(numpy 기본 선형 보간: 정렬 위치 (m−1)·x/100). 분자 그래프는 둘의 교집합: {a,b} ∈ E ⇔ 상호 kNN ∧ d(a,b) ≤ ε (molecule-theory 정의 2·(a)).

수직선 6점. A 0 · B 1 · C 2 · D 5 · E 6 · F 10, 거리는 차이의 절댓값. 쌍 15개의 거리를 정렬하면 [1,1,1,2,3,4,4,4,5,5,5,6,8,9,10]. Q20: 위치 (15−1)·0.2 = 2.8 → 1 + 0.8·(2−1) = 1.8. Q30: 위치 4.2 → 3 + 0.2·(4−3) = 3.2. k = 2 이웃 목록: A[B,C] · B[A,C] · C[B,A] · D[E,C] · E[D,C] · F[E,D]. 상호인 쌍은 AB · AC · BC · DE 넷. 만족하지 않는 예: C–D 는 D 의 목록에 C 가 있지만 C 의 목록에 D 가 없다(한쪽 kNN) — survey §각도2 실측 "상위 200 중 130 이 거의 이웃(한쪽 kNN15)"이 바로 이 종류의 쌍이다. F 는 상호 이웃 0 → 고립.

교집합이 분자를 정한다(Q10 슬라이더의 원리). pct 20(ε 1.8): 상호 kNN 넷 중 d ≤ 1.8 인 것은 AB·BC·DE — AC(=2)가 탈락해 삼각형이 없다. pct 30(ε 3.2): AB·AC·BC·DE 전부 통과 → 분자 {A,B,C} 탄생. 2.7 공통 이웃 · Adamic–Adar 지수

정의 7 · 링크 예측 점수 인접하지 않은 두 노드 x, y 에 대해 공통 이웃 수 CN(x,y) = |N(x) ∩ N(y)|, Adamic–Adar 지수 AA(x,y) = Σz ∈ N(x)∩N(y) 1 / log deg(z) (자연로그; networkx 도 같다). 공통 이웃이 저차수일수록 무겁다 — 모두와 이웃인 허브는 "둘이 특별히 가깝다"는 증거가 약하기 때문.

허브 그래프 H. 엣지 7개: h–x, h–y, h–p, h–q, h–r, p–x, p–y. 차수: h 5 · p 3 · x 2 · y 2 · q 1 · r 1. ln 2 = 0.6931, ln 3 = 1.0986, ln 5 = 1.6094. AA(x,y): 공통 이웃 {h, p} → 1/ln 5 + 1/ln 3 = 0.6213 + 0.9102 ≈ 1.5316(반올림 전 값의 정확한 합, CN 2). AA(q,r): 공통 이웃 {h} → 0.6213(CN 1). AA(x,q) = AA(p,q) = 0.6213. 저차수 p 하나가 허브 h 보다 무겁다(0.91 > 0.62) — 그래서 x–y 가 1위. 만족하지 않는 예: x–h 는 이미 인접이라 후보가 아니다(코드의 direct 집합). 차수 1 노드(q, r)는 두 노드의 공통 이웃이 될 수 없고 1/ln 1 은 정의되지 않는다 — 코드가 deg < 2 를 건너뛰는 이유.

프로젝트에서의 뜻. 허브 h 는 목록형 위키 원자(모두와 이웃)의 모형이다. AA 의 log 할인은 이론상 h 의 기여를 줄이지만 survey §각도2 실측에서는 그래도 목록형이 상위를 지배해(76/200), 3차에서 공통 이웃의 목록형 비율(list_like_cn_share)로 과반이면 제외했다. bridges 는 같은 점수에 거리 d 를 곱한다(멀지만 공통 이웃이 잇는 쌍 = 허브형 후보).

2.8 이분 매칭 · 헝가리안 알고리즘(선형 할당)

정의 8 · 할당 문제 두 집합 new = {Bi}, old = {Aj} 와 비용 C[i,j] 가 있을 때, 매칭은 끝점을 공유하지 않는 (Bi, Aj) 쌍의 집합. 선형 할당은 Σ C[i,σ(i)] 를 최소로 하는 일대일 σ 를 찾는 것. 헝가리안 알고리즘은 이를 O(n³)에 정확히 푼다(그리디는 순서에 따라 틀릴 수 있다). 계보에서는 C = 1 − J(자카드), 후보(J ≥ 0.5)가 아닌 칸은 벌점 NO_MATCH.

모듈성 Q · Louvain/Leiden Louvain reject · Leiden adopt(미구현)

정의. 분할 {c} 에 대해 Q = Σc [ Lc/m − (dc/2m)² ] — Lc 는 c 안의 엣지 수, dc 는 c 의 차수 합, m 은 전체 엣지 수. "무작위였다면 기대되는 내부 엣지"보다 얼마나 많은가.

예. 두 삼각형 {A,B,C}, {D,E,F} 를 C–D 로 이은 그래프(m = 7, dc = 7 씩): Q = 2·(3/7 − (7/14)²) = 2·(0.4286 − 0.25) = 0.3571. 전부 한 커뮤니티면 0, {AB}{CD}{EF} 면 0.0816. Louvain 도 같은 두 삼각형을 낸다.

k-core · k-truss reject(1차 실측)

정의. k-core: 모든 노드의 차수가 ≥ k 인 극대 부분그래프(차수 < k 노드를 반복 제거). k-truss: 모든 엣지가 ≥ k−2 개 삼각형에 속하는 극대 부분그래프.

예(G1). core number: A,B,C = 2 · D,E = 1 · F = 0 (E 제거 → D 차수 1 제거 → {A,B,C} 만 2-core). 3-truss 엣지 = {AB, AC, BC} = 삼각형 = 3-클리크 멤버십과 같다.

왜 멈추나. 장난감에서는 3-truss 와 삼각형의 노드 집합이 같았다. 프로젝트 실측에서는 k ≥ 4 truss 의 노드가 모두 기존 클리크·periphery 안에 있었다 — 기존 묶음 밖의 원자를 추가로 찾지는 못했다는 뜻이며, 클리크 멤버십과 완전히 같다는 뜻은 아니다. 얹을 등급이 없다.
