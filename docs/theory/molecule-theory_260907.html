원자가 서로 가까운 이유는 그 사이에 없는 것이 있기 때문이다 —
근접 그래프에서 개념을 가추하는 분자(molecule) 이론

사용자의 제안: 원자마다 임베딩 벡터를 두고, 서로 가까운 원자들이 모든 쌍에서 가까우면 그 묶음을 하나의 개념으로 보아 분자(molecule)라 부르고 이름을 붙이자. [프랑수아 1세, 설계·건축, 이탈리아]가 모이면 '다빈치'가 나타난다. 다빈치가 나중에 원자로 발견되면 그 연결을 기록한다. 이 문서는 그 제안을 단체 복합체(simplicial complex)·형식 개념 분석·가추 논리의 언어로 형식화하고, 어디가 이미 옳고 어디를 고치면 더 강해지는지를 밝힌다. 결론부터: 사용자가 그린 "A–B, B–C, A–C 가깝고 A–D 멂 ⇒ {A,B,C}" 규칙은 정확히 Vietoris–Rips 복합체의 극대 단체이고, '다빈치'를 붙이는 행위는 Peirce 의 가추(abduction)다 — 그래서 분자는 사실이 아니라 가설 등급이며, 가설이 원자로 환원(reification)될 때 검증 가능한 예측을 낳는다.

분자 = 극대 클리크 = 극대 단체 이름 붙이기 = 가추(abduction) 상태: hypothesis — 사실·주장과 분리 전역 ε 대신 지속성(persistence)으로 안정도 교집합형 vs 허브형 — 두 종류의 분자
아이디어

사용자의 제안을 명제로 분해하면

①거리

모든 원자에 임베딩 벡터를 두고 쌍별 거리를 구한다. "가깝다"의 기준은 전체 거리 분포의 하위 x%이고, x 는 그때그때 조절한다.

②결합 규칙

A–B, B–C, C–D 가 가깝고 A–C 도 가깝지만 A–D 가 멀면 {A,B,C}만 분자다. 즉 분자 안의 모든 쌍이 가까워야 하고, 한 쌍이라도 멀면 그 원자는 들어오지 못한다.

③시점성

원자는 계속 늘고 바뀌므로 분자는 시점별로 다르다. 분자는 원자와 다른 이름(molecule)으로 따로 둔다(docs/knowledge/molecule/).

④명명과 문서

분자마다 그룹을 부르는 이름과 그 지식의 특징, 관련된 것들을 검색해 문서를 쓴다. [프랑수아 1세, 설계·건축, 이탈리아] → '다빈치'.

⑤환원(reification)

'다빈치'도 원자가 될 수 있지만 그 전에 유추된 것이라 분자로 둔다. 나중에 원자로 발견되면 원자–분자 연결을 기록한다.

⑥설명 원리

"x 라는 단일 개념이 주변의 a, b, c 라는 외부 다수 개념의 교집합 또는 연관개념으로 설명 가능하다."

이 문서의 주장. ②는 그래프 이론의 극대 클리크이자 위상수학의 극대 단체다(§2). ⑥의 "교집합 또는 연관"은 서로 다른 두 구조 — 교집합형(공통 내연)과 허브형(공통 이웃) — 이고 둘의 검증 방법이 다르다(§3). ④의 명명은 연역도 귀납도 아닌 가추라서 분자는 반드시 가설 등급이어야 하며(§6), ⑤의 환원은 가설이 예측을 낳고 시험받는 유일한 순간이다. ①의 "하위 x%"는 임계값 하나가 아니라 필트레이션으로 두면 파라미터가 데이터에서 나온다(§4). 그리고 오늘 blind/aided 실험이 만든 추론 계층(unaided/aided)은 이 이론의 맨 아래층 — 지각(perception)이 어디까지 닿는가 — 을 채운다(§4·§5).
형식화

근접 그래프 · 클리크 · 단체 복합체

사용자가 그림으로 그린 규칙을 그대로 수학으로 옮기면 알려진 대상이 나온다. 그 대상의 이름을 알면 그 대상이 가진 정리와 알고리즘을 다 쓸 수 있다.

정의 1 · 원자와 임베딩 시점 t 의 원자 집합을 At, 임베딩을 φ : At → Sd−1(단위 구면; 정규화된 문장 벡터)라 한다. 거리는 코사인 거리 d(a,b) = 1 − ⟨φ(a), φ(b)⟩. 텍스트 = 제목 + 본문 + 태그 + 엔티티(레이어·범주 접두).
정의 2 · ε-근접 그래프 임계 ε 에 대해 Gε = (At, Eε), Eε = { {a,b} : d(a,b) ≤ ε }. 사용자의 "평균거리에서 하위 x%"는 ε = Qx(d), 즉 전 쌍 거리의 x-백분위수다.
정의 3 · 분자 M ⊆ At 가 분자라 함은 (i) |M| ≥ 3, (ii) ∀ a,b ∈ M : d(a,b) ≤ ε(상호 근접), (iii) 극대(M 에 어떤 원자를 더해도 (ii)가 깨짐). 즉 분자 = Gε 의 극대 클리크(maximal clique), 크기 ≥ 3.
사용자의 예를 검증한다. A–B, B–C, C–D, A–C 가깝고 A–D 멂. {A,B,C}는 세 쌍이 모두 가까우니 클리크다. D 를 넣으려면 A–D 도 가까워야 하는데 멀다 → (ii) 위반 → D 배제. {B,C,D}가 클리크인지는 B–D 에 달렸는데 진술에 없다 — 가깝다면 {B,C,D}도 별개의 분자가 되고(C 는 두 분자에 속한다), 멀다면 C–D 는 분자를 이루지 못하는 외로운 변(edge)이다. 둘 중 어느 경우에도 {A,B,C,D}는 분자가 아니다. 사용자의 직관이 극대 클리크 정의와 정확히 일치한다.

2.1 이것은 위상수학에서 이미 이름이 있다 — Vietoris–Rips 복합체

점집합 X 와 ε 에 대해 VRε(X) 는 "모든 쌍이 ε 이내인 부분집합"을 단체(simplex)로 갖는 복합체다. 크기 k 의 클리크는 (k−1)-단체: 변(2)·삼각형(3)·사면체(4)…. 그러므로

분자(크기 k) = VRε(At) 의 극대 (k−1)-단체   ·   분자 원장 = VRε(At) 의 극대 단체 목록

사용자의 그림에서 {A,B,C}는 채워진 삼각형이고 C–D 는 변만 있는 선이다. "채워짐"이 개념의 존재를 뜻한다는 것이 이 이론의 핵심 은유이자 형식이다.

2.2 시점성 — 필트레이션과 내용 주소

정의 4 · 필트레이션 ε 를 0 에서 키우면 VRε ⊆ VRε' (ε ≤ ε') — 단체는 태어나기만 하고 죽지 않는다(그러나 극대 단체는 더 큰 단체에 흡수되며 극대성을 잃는다). 분자 M 이 극대 단체로 존재하는 ε 의 구간 [εbirth(M), εabsorb(M)) 의 길이를 지속성(persistence)이라 한다.
정의 5 · 분자 식별자 id(M) = "mol_" + sha1(sort(ids(M)))[:12]. 같은 원자 구성이면 시점·ε 와 무관하게 같은 분자다. 스냅샷은 (t, ε 또는 x, k, knn) 튜플과 그때의 극대 단체 목록이다. At 가 바뀌면 분자가 태어나고(새 원자가 삼각형을 닫음), 죽고(멤버 소멸), 합쳐지고(두 삼각형이 사면체로), 갈라진다(멤버 갱신으로 변이 끊김) — 이 계보 이벤트가 시점성의 실체다.
의미론

왜 상호 근접이 "개념"인가 — 두 종류의 분자와 가추

사용자는 "교집합 또는 연관개념"이라 했다. 이 '또는'은 실제로 서로 다른 두 구조다. 구조가 다르면 이름을 붙이는 논리도, 검증하는 방법도 다르다.

3.1 교집합형 분자 — 형식 개념 분석(FCA)의 개념

Wille 의 형식 개념 분석에서 개념 = (외연 G, 내연 M) 의 갈루아 쌍이다: G 는 M 의 모든 속성을 가진 대상 전부, M 은 G 의 모든 대상이 공유하는 속성 전부. 임베딩 근접은 "속성을 공유한다"의 연속 근사이므로, 분자 = 외연, 이름 = 내연을 한 단어로 부른 것이다. 예: [노르웨이 노란 중앙선, 노르웨이 방향표지 노란 배경, 노르웨이 목재 집] → 내연 "노르웨이 도로·건축 시각 어휘" → 이름 "노르웨이 메타". 이런 분자의 이름은 상위 범주(genus)이고, 검증은 내연 열거로 한다 — 멤버 전부가 실제로 공유하는 속성을 적어 낼 수 있으면 통과.

3.2 허브형 분자 — 부재하는 노드와 가추

사용자의 예 [프랑수아 1세, 설계·건축, 이탈리아] → '다빈치'는 교집합이 아니다. 프랑수아 1세와 이탈리아 건축은 공유 속성이 거의 없다. 셋이 가까운 이유는 셋 모두와 강하게 연결된 하나의 노드(다빈치)가 그래프에 없기 때문이다 — 그 노드가 있었다면 셋은 별(star)로 연결됐을 텐데, 없으니 그 그림자가 삼각형으로 남았다. 확률 그래프 모형에서 이것은 잠재 변수(latent variable)다: 관측 변수 a,b,c 가 서로 상관되지만 x 를 조건으로 하면 독립이 되는 구조. 논리학에서 이 추론은 Peirce 의 가추(abduction)다.

규칙: x 이면 a, b, c   ·   관찰: a, b, c 가 함께 있다   ⇒   가설: x   (진리 보존 아님 — 가장 좋은 설명의 선택)

가추는 연역처럼 필연적이지 않고 귀납처럼 사례를 일반화하는 것도 아니다. "만약 x 가 참이라면 a,b,c 가 당연해진다"는 설명력으로 x 를 도입한다. 그래서 (1) 같은 삼각형에 여러 x 가 후보로 설 수 있고(다빈치 / 르네상스 / 앙부아즈 성), (2) x 는 시험받아야 한다. 분자 문서의 status: "hypothesis" 는 장식이 아니라 이 논리적 지위의 표기다.

∩교집합형 (내연 명명)

  • 이름 = 공유 속성의 상위 범주
  • 검증 = 내연 열거(멤버 전부가 가진 속성 ≥ 2개)
  • 환원되면 상위 원자(scope 넓음)로 나타남
  • 임베딩이 잘 잡는다 — 같은 어휘장

✦허브형 (잠재 노드 명명)

  • 이름 = 멤버를 모두 설명하는 부재 개체
  • 검증 = 별 조건: x 를 임베딩했을 때 ∀m∈M d(x,m) < maxm,m' d(m,m') — x 가 삼각형 안쪽에 있어야 한다(§6)
  • 환원되면 멤버 각각과 refs 로 연결되는 허브 원자
  • 임베딩이 놓치기 쉽다 — 멤버 간 어휘 공유가 적어 거리가 멀 수 있음 → §4(h)
구분법. 분자의 내부 거리가 고르게 짧고(직경 ≈ 평균) 멤버 제목에 공통 명사가 있으면 교집합형이 유력하다. 내부 거리가 고르지만 공통 명사가 없고, 이름 후보를 임베딩하면 그것이 중심(centroid)에 멤버들보다 더 가깝다면 허브형이다. 명명 도구는 두 유형을 모두 내게 하고(why_these_cohere), 사후 검증(§6)이 어느 쪽인지 가른다.

3.3 부정 증거 — D 가 배제된 것도 지식이다

"{A,B,C}는 x 지만 D 는 아니다"는 그 자체로 x 의 경계를 말한다. 논리 형식으로는 x(A)∧x(B)∧x(C)∧¬x(D), 즉 어제 기획서(atom-dialogue §3)의 반사실적 판별자("핀란드였다면 대신 …")와 같은 꼴이다. 분자 문서에 "가장 가까웠지만 들어오지 못한 원자"(near-miss, 최소 한 쌍이 ε 를 넘긴 것)를 기록하면, 그 분자의 개념이 어디서 끝나는지가 드러난다. 이것이 판별자 원자를 만드는 새로운 원천이 된다.

지각에서 가추까지 — 원자에 인식론적 층을 매긴다

오늘의 blind/aided 실험(docs/knowledge/baseline/)은 "이 사실은 로드뷰만 보고 나온 것인가, 지도(보조 지식)가 있어야 나온 것인가"를 원자 단위로 가른다. 이 계층은 분자 이론의 바닥층이다 — 분자가 어떤 종류의 지식 위에 서 있는지를 말해 준다.

실측 — 14건, 2026-09-07 (docs/knowledge/baseline/README.md). 국가 적중 blind 14/14 · aided 14/14. 좌표 오차 중앙값 blind 1.54 km · aided 1.47 km(거의 같음), 평균 15.07 vs 9.57 km — 차이는 꼬리에서 난다(스페인 46→0.5, 일본 40→7, 카자흐스탄 102→102, 독일 4.9→0.07). 도달 level: blind 13/14 district. 감사 판정 14건: map-leaked-answer 8 · map-helped 4 · blind-sufficient 2. 원자 계층: unaided 191 · aided 22 · blind-only 24 (aided 9%). aided 22건 중 5건은 문자 그대로 지도 라벨이다("Map inset showing Route 711", "Map overlay naming FV-2 road", "Map labels for QL37 corridor", "Map panel with Munich district place names", "Map label for Beyneu settlement") — 정답 누출이 원자로 굳어지는 경로가 실재한다. 나머지 aided 는 지도가 장소를 알려준 뒤 모델이 기억에서 꺼낸 장소 사실(투르쿠의 스웨덴 유산, 기타야마 임업, 카나리아 도로 코드)이다 — 관찰이 아니라 회상이며, 그래서 aided 층은 "지각"이 아니라 "지식 인출"의 층이다. 해석: 국가·지역 판별은 로드뷰만으로 이미 충분하고(간판·상호·행정 브랜딩이 지명을 직접 준다), 지도는 마지막 1 km 와 실패 사례의 구제에만 기여한다. 따라서 (i) 지도 라벨 유래 cue 는 P1 재료에서 제외해야 하고, (ii) "판별자가 도움이 됐다"는 주장은 blind 모드의 꼬리(오차 > 10 km 건수)로 측정해야 한다.
개선

아이디어를 더 강하게 만드는 아홉 가지

(a)전역 ε 의 밀도 편향 → 국소 척도

원자 밀도가 지역마다 다르다(아이슬란드·크로아티아 수백 vs 카자흐스탄 수 건). 전역 x-백분위 하나면 밀집 지역은 거대 클리크로 뭉치고 희소 지역은 분자가 안 생긴다. 상호 k-NN 그래프(둘이 서로의 상위 k 이웃) 또는 각 점의 k 번째 이웃 거리로 정규화한 국소 εa 를 전역 ε 과 교집합한다. 현재 구현(pct ∩ knn)이 이 절충이다.

(b)임계 하나 → 지속성 점수

"그때그때 조절"을 필트레이션으로 바꾼다: 여러 ε 에서 극대 단체를 구해 각 분자의 생존 구간 길이를 안정도로 기록한다. 넓은 구간에서 살아남는 분자가 진짜 개념이고, 한 ε 에서만 보이는 분자는 노이즈다. 파라미터가 사람의 손을 떠나 데이터로 간다.

(c)클리크의 취약성은 그대로 두되 병합만

클리크는 한 변만 끊겨도 깨진다. 준클리크·k-코어로 완화하면 "A–D 가 멀면 D 배제"라는 사용자의 원칙(직경 조건)이 무너진다. 그래서 직경 ≤ ε 은 원칙으로 유지하고, 거의 같은 멤버의 클리크(자카드 ≥ 0.75)만 하나로 본다. 클리크 퍼콜레이션(공유 2개면 병합)은 D 를 끌어들이므로 쓰지 않는다.

(d)명명의 시험 — 가추는 시험받아야 한다

이름 x 를 같은 임베딩 공간에 넣고 세 가지를 잰다: ① 중심성 — d(x, centroid(M)) 이 멤버 평균보다 작은가, ② 별 조건 — ∀m d(x,m) < diameter(M) 인가(허브형), ③ 외부 근거 — 웹 검색 인용이 있는가. ①②를 통과하면 개념명, ③만 있으면 라벨, 다 실패하면 미명명으로 남긴다.

(e)환원(reification)은 예측이다

'다빈치'가 원자로 들어오면 (i) 멤버들과의 거리가 멤버 간 거리보다 짧아야 하고(별 조건의 사후 검증), (ii) 새 원자의 refs 가 멤버를 가리켜야 한다 — refs 의 세 번째 용도(expansion 계보·공동 인용·분자 환원). 예측이 틀리면(다빈치 원자가 삼각형 밖에 있으면) 그 분자의 이름은 폐기된다. 환원이 곧 시험이다.

(f)거대분자 — 개념 위계

분자 중심(centroid) 벡터로 2차 근접 그래프를 만들면 분자의 분자가 나온다 — FCA 의 개념 격자에 해당한다. 그러나 가설 위의 가설이라 깊이 2 까지만 허용하고 문서에 계층 깊이를 명시한다.

(g)near-miss 를 판별자로

분자마다 "가장 가까웠지만 한 쌍 때문에 배제된 원자" D 를 기록한다. "{A,B,C}는 x, D 는 아님"은 반사실적 판별자와 동형(§3.3)이라, 대화 base 의 propose_atom(kind=discriminator) 재료가 된다.

(h)임베딩의 지명 편향 → 탈지명화 병행

다국어 문장 임베딩은 표면 어휘에 민감해 같은 지명이 반복되는 원자가 뭉친다 — 그러면 분자가 "개념"이 아니라 "국가 폴더"가 된다. 엔티티·지명을 마스킹한 텍스트로 두 번째 임베딩을 만들어 병행하고, 두 공간에서 모두 가까운 쌍만 개념적 근접으로 본다. 첫 실행 결과가 국가별로 뭉치면 이 장치를 켠다(§7).

(i)분자에 지각 의존도·등급 합성

멤버의 층(§4)을 집계해 분자마다 tier_mix(L0/L1/L2 비율)와 derivation_mix(web/vision)를 붙인다. 상용 아틀라스 모드는 web 유래 멤버만으로 재계산한 분자만 쓴다(시장조사 §3-3, atom-dialogue §8).

# 1. 임베딩 (시스템 Python, GPU) — 증분: updated 가 같으면 재사용
V = normalize(embed([layer+category+title+body+tags+entities for a in atoms]))

# 2. 거리와 임계 — 전역 백분위 ∩ 상위 k 이웃
D = 1 - V @ V.T
eps = percentile(D[upper], pct)                 # 사용자의 "하위 x%"
E = {(a,b) : D[a,b] <= eps and b in kNN(a,k) and a in kNN(b,k)}   # 상호 k-NN 교집합

# 3. 분자 = 극대 클리크(= VR_eps 의 극대 단체), 크기 ≥ 3 ; 직경 조건은 정의상 만족
M = [c for c in maximal_cliques(G(E)) if len(c) >= 3]
M = merge_if_jaccard(M, 0.75)                   # 거의 같은 클리크만 병합 — 퍼콜레이션 아님
for m in M: m.id = "mol_" + sha1(sorted(m))[:12]; m.cohesion = mean(D[m]); m.diameter = max(D[m])
           m.near_miss = argmin_{d ∉ m} max_{a∈m} D[a,d]      # (g) 배제된 최근접

# 4. 지속성 (b) — 여러 eps 에서 반복해 생존 구간 기록
for pct in [1, 2, 3, 5]: snapshot(pct) ; persistence[m.id] = [pct_birth, pct_absorb)

# 5. 명명 = 가추 (LLM, 닫힌 세계 + 웹 검색 ≤ 2) → status: hypothesis
doc = llm(molecule_doc, members=m, tools=[web_search])   # name, why_these_cohere, related, missing_atoms

# 6. 시험 (d) — 이름을 같은 공간에 넣어 중심성·별 조건 확인
x = embed(doc.name); grade = "concept" if d(x,centroid) < mean_d and all(d(x,m) < diameter) else "label"

# 7. 환원 (e) — 이름이 원자로 존재/등장하면 연결 기록 + 별 조건 사후 검증
for a in atoms: if slug(a) == doc.slug or slug in a.entities: link(m, a); verify_star(a, m)

한계

이 이론이 틀릴 수 있는 지점

  • 임베딩 거리 ≠ 논리적 연관. 문장 임베딩은 어휘·주제 유사도를 잡는다. "프랑수아 1세"와 "이탈리아 건축"은 어휘가 안 겹쳐 멀 수 있다 — 허브형 분자는 임베딩만으로는 발견되지 않을 가능성이 크다. 허브형은 오히려 관계 그래프(extract.py 의 행위자 관계, 공동 인용 refs)에서 공통 이웃으로 찾는 것이 맞고, 임베딩 클리크는 교집합형에 강하다. 두 그래프를 합쳐야 사용자의 '다빈치' 예가 실제로 나온다.
  • 클리크 폭발. 밀집 영역에서 극대 클리크 수는 지수적으로 늘 수 있다. 상호 k-NN 제한과 pct 조절이 방어선이고, 그래도 넘치면 k-클리크 열거를 크기 ≤ 12 로 자른다.
  • 이름 환각. LLM 은 어떤 삼각형에도 그럴듯한 이름을 붙인다. (d)의 기하학적 시험과 웹 근거 없이는 이름을 "개념"이라 부르지 않는다.
  • 표본 편향. 원자 1,290개는 40개국 184장 캡처와 확장 패스에서 왔다. 분자는 우리가 어디를 찍었는가를 반영할 뿐 세계의 개념 구조가 아니다. 분자 문서는 반드시 멤버 수·국가 수·기간을 적는다.
  • 시점성의 비용. 스냅샷마다 명명을 다시 하면 비용이 선형으로 는다. 내용 주소 id 로 같은 구성은 재명명하지 않고, 바뀐 분자만 다시 명명한다.
  • 지각 계층의 표본 크기. blind/aided 는 14건 실험이다. 계층 판정(0.40 매칭)은 첫 건으로 보정한 값이라 다른 언어·다른 규모의 원자에서는 재보정이 필요하다.
다음

실행과 검증 순서

  1. 1차 스냅샷 확인(docs/knowledge/molecule/) — 분자가 국가 폴더로 뭉치는지 본다. 뭉치면 (h) 탈지명화 임베딩을 켜고 두 공간의 교집합으로 재계산.
  2. (d) 시험 구현 — 이름을 임베딩해 중심성·별 조건을 계산하고 문서에 grade: concept|label|unnamed 기록.
  3. (b) 지속성 — pct 1/2/3/5 스냅샷을 자동으로 남기고 분자별 생존 구간을 index 에.
  4. (g) near-miss 를 분자 문서에 추가하고, 대화 base(atom-dialogue) 의 판별자 제안 재료로 연결.
  5. 허브형 발견용 관계 그래프 — extract.py 관계 + 공동 인용 refs 에서 공통 이웃 삼각형을 찾아 임베딩 클리크와 비교. '다빈치' 유형은 여기서 나온다.
  6. (i) 등급 합성 — baseline 의 tier 와 derivation 을 분자에 집계. 상용 모드는 web-only 재계산.
