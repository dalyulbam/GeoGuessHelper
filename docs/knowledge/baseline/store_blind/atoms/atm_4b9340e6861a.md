# Munich inner-ring districts show patchy post-war reconstruction pattern

`atm_4b9340e6861a` · **culture** / city · cell `u284p2k`

Munich's inner south-eastern districts (Haidhausen, Au, Giesing, Ramersdorf) display an alternation of plain 1950s post-war render apartment blocks with surviving Jugendstil/Gründerzeit corner tenements, reflecting patchy WWII bombing damage rather than uniform destruction. This contrasts with Schwabing's more continuous upmarket Gründerzeit fabric and with western districts like Laim/Pasing which have more uniform 1960s slab housing.
