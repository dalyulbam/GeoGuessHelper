# Lanzarote's César Manrique aesthetic building code

`atm_ace3b619ddf6` · **architecture** / region · cell `esvzdqh`

Lanzarote enforces an island-wide architectural code inspired by artist César Manrique: buildings must be white cubic volumes with flat roofs, using green woodwork near the coast and brown/wood tones inland; large pitched or pantile roofs are essentially absent. This distinguishes it visually from neighboring Fuerteventura, whose resorts use varied styles including orange terracotta pantile hipped roofs.
