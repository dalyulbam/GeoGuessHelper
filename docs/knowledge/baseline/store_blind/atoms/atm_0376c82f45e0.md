# Kazakh oil-belt suburban housing pattern

`atm_0376c82f45e0` · **culture** / region · cell `v0ny37g`

In Kazakhstan's western oil-producing regions (Mangystau, Aktobe), new private wealth manifests as large brick or block villas with steep pitched metal roofs, built behind solid perimeter walls on bare, unlandscaped sand plots at settlement edges. This contrasts with Uzbek flat-roofed adobe courtyard compounds with poplar rows, and with Turkmen roadside settlements marked by whitewashed kerbs and Latin-script Turkmen signage.
