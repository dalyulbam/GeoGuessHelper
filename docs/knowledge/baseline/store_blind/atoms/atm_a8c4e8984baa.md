# Icelandic orthography uses eth (ð) and thorn (þ)

Icelandic retains the Old Norse letters eth (ð) and thorn (þ), distinguishing it from Faroese (which uses ø and Danish-influenced spelling) and Norwegian (which lacks both letters). Street-name elements like 'braut', 'gata' and 'vegur' combined with ð/þ are diagnostic of Icelandic signage versus other North Atlantic Nordic territories.
