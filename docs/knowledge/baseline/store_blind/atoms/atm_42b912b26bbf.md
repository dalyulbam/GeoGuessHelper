# Jordanian mobile number prefixes (077/078/079)

`atm_42b912b26bbf` · **language** / country · cell `sv9x8tu`

Jordanian mobile phone numbers use the 10-digit local format starting with 077 (Zain), 078 (Umniah) or 079 (Orange). This block is distinct from neighboring countries: West Bank Palestinian mobiles use 059x/056x, Syrian mobiles use 093/094/098, and Lebanese numbers are 8-digit starting with 03/70/71/76/81. Phone numbers visible on shop signage are a reliable discriminator between Levantine countries.
