# Canary Islands road-code prefixes identify individual islands

`atm_68d536a3a07f` · **geography** / polity · cell `esvzdqh`

Each Canary Island has its own road-network prefix distinct from mainland Spanish A-/AP- codes: FV- for Fuerteventura, LZ- for Lanzarote, TF- for Tenerife, GC- for Gran Canaria. These prefixes, visible on maps and road signage, allow immediate identification of which island a scene belongs to.
