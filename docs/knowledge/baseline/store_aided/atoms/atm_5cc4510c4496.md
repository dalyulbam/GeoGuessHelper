# Gulf state mobile numbering plans differ by country

`atm_5cc4510c4496` · **language** / country · cell `thrxzsf`

Gulf Cooperation Council countries use distinct mobile prefixes: UAE mobiles start with 050/054/055/056/052; Saudi Arabia mobiles start with 05x but pair with different landline codes and often Hijri-only permit dates; Oman uses 9xxx eight-digit mobile numbers; Qatar and Kuwait mobiles start with 3/5/6/7/9 digits in different groupings. These formatting differences on printed shop signage are a reliable way to distinguish Gulf countries from one another.
