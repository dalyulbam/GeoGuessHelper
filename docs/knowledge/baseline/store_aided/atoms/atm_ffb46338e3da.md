# Standardized recycling igloo labelling across Czechia

`atm_ffb46338e3da` · **culture** / country · cell `u2f2t6k`

Czech municipalities use color-coded 'igloo' recycling containers labelled PLASTY (plastics), PAPÍR (paper), SKLO (glass, often split into 'čiré'/clear and 'směs'/mixed), and KOVOVÉ ODPADY (metal waste), frequently with a printed thank-you message like 'DĚKUJEME VÁM, ŽE TŘÍDÍTE' (thank you for sorting). This uniform national labelling scheme is a strong country-level identifier distinct from Austrian ARA-branded bins or Polish/Hungarian equivalents.
