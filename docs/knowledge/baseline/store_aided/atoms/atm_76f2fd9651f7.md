# Bohemian inland village fabric vs Moravian and Silesian vernacular

`atm_76f2fd9651f7` · **architecture** / region · cell `u2f2t6k`

Inland Bohemian villages typically show rendered pastel farmhouse ranges arranged around an irregular green, often with a granary (špejchar), amid rolling arable plateaus with conifer plantations. This contrasts with Moravian regions like Slovácko/Haná, which favor long single-row streets of gable-end 'žudro' cottages, vineyard cellars, and a prominent baroque church on a linear green, and with Czech Silesia's brick-heavy, mining-influenced terraced vernacular.
