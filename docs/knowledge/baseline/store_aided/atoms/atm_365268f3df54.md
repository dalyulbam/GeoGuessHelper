# Kazakh Caspian housing pattern vs Russian-settler and Uzbek-oasis housing

`atm_365268f3df54` · **culture** / polity · cell `v0ny37g`

In the Kazakh Caspian/Ustyurt zone, town-edge housing consists of widely spaced detached brick or rendered houses with red metal hipped roofs behind solid painted perimeter walls, set on an unlandscaped sandy grid. This differs from Russian-settler districts (timber izba houses, kitchen gardens, Orthodox village layout) and Uzbek sedentary oases (dense mudbrick mahalla courtyard clusters with mulberry/poplar tree lines).
