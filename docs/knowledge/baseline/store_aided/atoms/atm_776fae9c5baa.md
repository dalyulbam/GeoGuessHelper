# Icelandic orthography marker: the letter eth (ð) and '-braut' street suffix

Icelandic retains the letter ð (eth), absent from Norwegian, Swedish, Finnish and Danish alphabets, though Faroese also uses ð. Icelandic street names commonly use compound suffixes like '-braut', '-vegur', or '-gata' for road types; the specific '-braut' suffix pattern combined with ð orthography helps distinguish Icelandic signage from Faroese, which lacks this street-suffix convention.
