# SADC region driving side and sign conventions distinguish from Australia

`atm_a0c094988a31` · **geography** / global · cell `k9fpcu8`

Southern African Development Community countries drive on the left, like Australia, but use red triangular yield/warning signage distinct from Australia's yellow-on-black diamond warning signs. Universal palisade-and-razor-wire security fencing on commercial and residential plots is a strong marker of southern Africa (especially South Africa) rather than Australia, which lacks this security architecture at comparable density.
