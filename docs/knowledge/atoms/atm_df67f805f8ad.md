# Kazakhstan's ongoing Cyrillic-to-Latin script transition

`atm_df67f805f8ad` · **language** / country · cell `v0nxmzr`

Kazakhstan is in a gradual, government-mandated transition from Cyrillic to Latin script for the Kazakh language, resulting in mixed signage where Latin loanwords (e.g., 'STOP') appear alongside Cyrillic place names and Soviet-template (GOST) road signs. This partial, transitional dual-script landscape distinguishes Kazakhstan from neighboring states that completed a script switch (Uzbekistan, Latin since 1995) or retained Cyrillic exclusively (Russia, Kyrgyzstan, Tajikistan).
