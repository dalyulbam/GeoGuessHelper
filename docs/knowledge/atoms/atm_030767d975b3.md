# Yellow kerbside no-parking line is a French road-marking convention

`atm_030767d975b3` · **geography** / country · cell `u0g1ehc`

France uses a continuous yellow line painted along the kerb edge to indicate no-stopping/no-parking zones, a convention not shared by Germany (which uses white kerb markings) or Belgium/Netherlands. This is a reliable street-level discriminator for identifying France among north-west European countries.
