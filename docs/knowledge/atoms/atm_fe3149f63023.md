# Cyrillic-script administrative lexicon variation across Slavic states

`atm_fe3149f63023` · **language** / global

Post-Soviet and Balkan Cyrillic-using states each preserve distinct administrative vocabularies inherited from different historical bureaucracies: Russia uses 'сельсовет' (selsoviet) legacy terms, Serbia 'месна заједница' (local community), North Macedonia 'општина' (opština), and Ukraine 'сільрада'. These lexical fingerprints allow rapid country identification on maps despite the shared script.
