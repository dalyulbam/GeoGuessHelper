# Indic scripts tied to state linguistic identity

`atm_cba815c32e45` · **language** / global

India's states are organized partly along linguistic lines, each with a state language and often a distinct script: Tamil Nadu uses Tamil script, West Bengal uses Bengali script, Gujarat uses Gujarati script, and Punjab uses Gurmukhi. This mirrors Maharashtra's use of Devanagari for Marathi, reflecting the 1956 States Reorganisation Act's linguistic-state principle.
