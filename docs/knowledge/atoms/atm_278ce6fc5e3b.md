# German-language street-suffix conventions across DACH region

`atm_278ce6fc5e3b` · **language** / global

German-speaking countries share a core set of street-name suffixes—'-straße/strasse' (street), '-gasse' (lane, especially common in Austria and older German cities), '-weg' (way), '-platz' (square), and '-allee' (avenue)—but usage frequency and orthography (Switzerland drops the ß, writing 'strasse') vary distinctly among Germany, Austria, and Switzerland.
