# Hausruck molasse hills vs Mühlviertel granite plateau in Upper Austria

`atm_2b6dc49fc1c4` · **geography** / region · cell `u299pj2`

In the Hausruckviertel the land is a set of short, steep, deeply dissected grass ridges with rounded beech-spruce crests and views that can catch a hazy Alpine line to the south. In the Mühlviertel you would instead see broad flat-topped plateau surfaces, frequent exposed granite boulders and drystone-granite plinths, more spruce monoculture and no southern high-ridge horizon. Uniform smooth render with no granite stonework, as here, argues against the Bohemian Massif.
