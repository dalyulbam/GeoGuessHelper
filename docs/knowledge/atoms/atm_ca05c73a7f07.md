# Icelandic route numbering ranges by region

`atm_ca05c73a7f07` · **geography** / country · cell `ge9h53m`

Iceland's secondary road numbers cluster by region: Reykjanes area roads use 4x numbers, north Iceland roads use 8x, east Iceland roads use 9x, and west Iceland/Snæfellsnes roads use distinct 2-3 digit numbers (50s range). Spur roads off the Ring Road (Route 1) with numbers in these ranges can help identify which region of Iceland a location is in.
