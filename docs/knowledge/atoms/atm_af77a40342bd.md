# Ottoman Arabic-script toponymy replaced by Turkish Latin alphabet reform

`atm_af77a40342bd` · **language** / country · cell `sxp75tx`

**시기**: 1928 ~ 1928

Prior to Mustafa Kemal Atatürk's 1928 alphabet reform, Ottoman Turkish was written in a Perso-Arabic script; place names and signage used Arabic script forms. The reform replaced this with the Latin-based Turkish alphabet including unique letters (ı, ş, ğ), a rapid top-down linguistic shift that erased centuries of Arabic-script toponymic tradition within a single generation.
