# Student-catering brands split Finnish university cities

`atm_a1ebb65130d5` · **culture** / city · cell `u6xzgj3`

In Turku, campus canteens carry the 'Unica' fork-and-leaf brand; in Helsinki you would instead see UniCafe/HYY Ravintolat, in Espoo/Otaniemi Aalto-AYY outlets, and in Tampere 'Juvenes'. A single canteen logo on an institutional facade therefore separates Finnish university cities that otherwise share identical 1960s panel architecture.
