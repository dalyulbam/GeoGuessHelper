# Tourism-core / industrial-satellite metropolitan split

`atm_c5e197941608` · **economy** / global

Many tourism-dependent metropolitan areas separate their service-driven historic core from manufacturing and logistics functions pushed to satellite municipalities: Venice's historic center relies on tourism while Marghera and Mestre on the mainland host industry and port logistics; Florence's tourism core contrasts with industrial estates in Prato and Sesto Fiorentino. This spatial division lets the core specialize in hospitality-driven land uses while satellites absorb warehousing, light manufacturing and commuter housing.
