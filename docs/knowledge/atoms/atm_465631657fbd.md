# SAD regional bus operator branding in Slovakia

`atm_465631657fbd` · **geography** / polity · cell `u2v27rh`

Slovak intercity buses are operated by regional SAD (Slovenská autobusová doprava) companies branded by their home region/city (e.g., SAD Žilina, SAD Trenčín, SAD Zvolen). The livery and destination text on buses (e.g., blue Iveco Crossway with 'ŽILINA' branding) can be used to identify which Slovak administrative region (kraj) a location belongs to.
