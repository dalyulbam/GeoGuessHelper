# Turkish toponymic lexicon markers (Camii, Bulvarı, Sokak, Caddesi)

`atm_9a486159e361` · **language** / country · cell `sxjrck3`

Turkish map labels commonly use terms like 'Camii' (mosque), 'Bulvarı' (boulevard), 'Sokak/Sk.' (street), 'Caddesi/Cd.' (avenue), and 'Çarşısı' (market/bazaar), written in Latin script with Turkish-specific letters (ı, ş, ğ, ç). This lexicon reliably distinguishes Turkey from Balkan Latin-script neighbors (Greek script in Greece; Cyrillic or Romanian terms like 'Strada'/'Bulevardul' in Bulgaria/Romania).
