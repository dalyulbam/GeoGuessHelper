# South Slavic diglossia markers: Serbian Cyrillic vs Croatian Latin

`atm_a58facd06de0` · **language** / global

Serbian and Croatian, mutually intelligible South Slavic languages, are distinguished visually by script rather than diacritics: Serbian signage commonly uses Cyrillic (АПОТЕКА for pharmacy) alongside Latin, while Croatian uses only Latin script with diacritics č, ć, š, ž, đ (ljekarna). This script-based discriminator functions like the Czech-Slovak diacritic split for geolocation purposes.
