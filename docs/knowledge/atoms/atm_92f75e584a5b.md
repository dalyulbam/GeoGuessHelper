# North Germanic languages retaining archaic letters

`atm_92f75e584a5b` · **language** / global

Faroese also retains ð and has its own compound toponym suffixes (-vík, -fjørður). Old English once used þ (thorn) and ð (eth), preserved today only in Icelandic and Faroese among living languages. This shared orthographic conservatism links Icelandic and Faroese as the most archaic living North Germanic tongues, both stemming from Old Norse.
