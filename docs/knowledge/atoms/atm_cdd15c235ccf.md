# Fuerteventura vs Lanzarote building codes and resort morphology

`atm_cdd15c235ccf` · **culture** / region · cell `esvzdq6`

Fuerteventura permits orange pantile hipped/pyramidal roofs on tourist resort architecture, contrasting with Lanzarote's strict low-rise white-cube building code (championed by César Manrique) that bans such tiled roofs and colored facades. This regulatory divergence between neighboring Canary Islands is a useful visual discriminator for resort architecture.
