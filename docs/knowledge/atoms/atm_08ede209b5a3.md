# Narrow-gauge railway abandonment in post-imperial hinterlands

`atm_08ede209b5a3` · **history** / global

Narrow-gauge railways built by imperial administrations to link ports or coasts to inland hinterlands were frequently abandoned in the 20th century as roads and standard-gauge lines replaced them, leaving derelict stations and trackbeds: examples include the Bosnian narrow-gauge network built under Austro-Hungarian rule, India's colonial-era narrow-gauge hill railways (some preserved, like the Darjeeling Himalayan Railway), and Portugal's abandoned narrow-gauge lines in the Douro valley.
