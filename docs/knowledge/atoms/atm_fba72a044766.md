# Slovak local-government terminology: starosta obce

`atm_fba72a044766` · **language** / country · cell `u2xj588`

Slovak municipal election signage uses phrases like 'starosta obce' (mayor of a municipality) and 'starostu obce [name]', with distinctive diacritics (ľ, ĺ, ô, ď, ň) and .sk web domains for local bodies/companies. This contrasts with Czech (which lacks these forms and uses ř, .cz domains), Polish ('wójt'/'burmistrz', ł/ą/ę), and Slovenian ('župan').
