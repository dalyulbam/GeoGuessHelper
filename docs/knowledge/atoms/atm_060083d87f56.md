# Maldives one-island-one-resort model

`atm_060083d87f56` · **economy** / country · cell `t8s44pj`

The Maldives pioneered a tourism model where each resort occupies its own entire island, uninhabited by locals, with guests flown or boated directly in, keeping tourist and local populations physically separate. This system, developed since the 1970s, concentrates each island's whole economy around a single hotel operator, similar in structure to isolated Croatian island hotels.
