# Distinguishing Sinhala from Tamil, Malayalam, and Bengali scripts

`atm_847c69212d36` · **language** / country · cell `tc2c139`

Sinhala script uses rounded, bubble-like circular glyphs, distinguishing it from Tamil (flatter, hooked forms), Malayalam (looping but more angular ligatures), and Bengali (continuous horizontal headstroke/matra connecting letters). This script differentiation is a primary method for distinguishing Sri Lanka from South Indian states (Kerala, Tamil Nadu) and Bangladesh in street-level geolocation.
