# Toponym suffixes distinguishing Indian linguistic macro-regions

Place-name suffixes are strong regional discriminators within India: '-nagar', '-ganj', 'chowki', 'dhal' indicate Hindi/Urdu-speaking Hindi Belt regions (UP, Bihar, MP); Gurmukhi script indicates Punjab/Haryana; Marathi suffixes like '-wadi' and '-peth' indicate Maharashtra; arid scrub and sandstone architecture indicate Rajasthan.
