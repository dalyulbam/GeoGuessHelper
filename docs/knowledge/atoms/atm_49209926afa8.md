# Municipal branding names the metro: use it before guessing the city

`atm_49209926afa8` · **geography** / region · cell `k9fpcu8`

South African metros brand sub-offices (traffic department, municipal court, fire & emergency) with the full metro logo, e.g. 'Nelson Mandela Bay Municipality', which pins the metro but not the town. In such a case, look for a retail directional sign naming the specific town; a satellite town like Uitenhage/Kariega hosts these metro sub-offices while the coastal Gqeberha core would show harbour/beachfront cues instead.
