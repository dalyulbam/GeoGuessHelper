# Tswana ward-based settlement pattern

`atm_2ecb8ee81d38` · **culture** / region · cell `keghd35`

Traditional Tswana towns and villages in Botswana (associated with polities such as the Bangwato, Bakwena, Bakgatla, Bangwaketse) are organized into named wards (e.g. Borotsi, Boseja, Dilaene) each historically linked to a kgotla (traditional court) and lineage grouping. Ward names visible on maps or signage can indicate which Tswana merafe (nation/chiefdom) territory a settlement belongs to.
