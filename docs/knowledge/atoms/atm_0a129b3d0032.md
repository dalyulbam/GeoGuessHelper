# Italian provincial road (SP) numbering and blue shield convention

`atm_0a129b3d0032` · **culture** / country · cell `spyrs4d`

Italy's provincial road network uses 'SP' (Strada Provinciale) numeric codes displayed on distinctive blue shield signage, administered per-province (e.g., the Pavia-series SP97/SP99/SP102/SP196 serving Voghera and Rivanazzano). Each Italian province maintains its own SP numbering series, so the specific number series visible on a map is a reliable way to localize within Italy and distinguish neighboring provinces or regions.
