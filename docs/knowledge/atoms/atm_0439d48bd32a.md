# Norwegian road-name suffix -vegen vs -veien as a north/south dialect marker

`atm_0439d48bd32a` · **language** / region · cell `ukmkre5`

In Norway, road names ending in '-vegen' (e.g. Dramsvegen, Kårvikvegen, Skagesundvegen) are typical of northern and western Norway, reflecting Nynorsk/dialectal spelling conventions, whereas the '-veien' suffix is more typical of eastern/southern Norway (e.g. Oslo region), which uses Bokmål-standard spelling. This distinction can help geolocate street-level imagery within Norway.
