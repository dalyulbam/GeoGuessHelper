# Seasonal return migration and diaspora remittances in Albania

`atm_5d9c6a60125a` · **economy** / country · cell `srq54gr`

Counter to permanent emigration, many Albanians abroad (notably in Italy, Greece, and Germany) send remittances that constitute a significant share of Albania's GDP, and some diaspora members return seasonally to work in the booming Albanian Riviera tourism sector or invest in coastal real estate, partially offsetting the labor drain described in the youth emigration pattern.
