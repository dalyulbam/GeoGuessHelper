# Missing snowmelt sprinklers do not rule out Hokuriku on minor lanes

`atm_eba3dc758411` · **geography** / region · cell `xn9k2th`

In Hokuriku (Ishikawa/Toyama/Niigata) the road-crown snowmelt sprinkler line (shosetsu paipu) is installed almost exclusively on urban streets and prefectural through-routes; on one-lane hamlet and forestry roads you see instead a plain white edge line, no nozzles and no snow poles. In Pacific-side Kanto you would see the same bare lane, so this absence is non-diagnostic and must not be used to push a guess to the Pacific side.
