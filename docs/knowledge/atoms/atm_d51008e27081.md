# Paraguay's post-2014 PY-prefixed route numbering system

`atm_d51008e27081` · **geography** / country · cell `6g0k8uc`

**시기**: 2014 ~ ?

Paraguay renumbered its national road network after 2014 using a 'PY' prefix followed by two digits (e.g., PY01, PY06, PY02), displayed on dark green directional signs in Spanish. This system is unique to Paraguay and distinguishes its roads from Argentina's RN/RP numbering, Brazil's BR-prefixed Portuguese-language rodovias, and Uruguay's unprefixed 'Ruta' numbers.
