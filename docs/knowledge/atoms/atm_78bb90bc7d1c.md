# German standardized red/white roadwork barriers (RSA)

`atm_78bb90bc7d1c` · **culture** / country · cell `u284p2g`

Germany uses a nationally standardized road-works barrier system (RSA - Richtlinien für die Sicherung von Arbeitsstellen) featuring red/white striped barrier boards with amber blinker lamps, visually distinct from Austrian and Swiss equivalents. This standardization makes temporary traffic-management furniture a usable discriminator for identifying Germany specifically within the German-speaking sphere.
