# Colombian calle/carrera street grid naming convention

`atm_91b8f6217bd1` · **language** / country · cell `d2g8r9w`

Colombian towns typically use a Cartesian street-naming system with 'Calle' (running one direction) and 'Carrera' (running perpendicular), numbered sequentially from a reference point, displayed on white-on-green blades with separate directional arrow plates. This convention distinguishes Colombia from neighboring Venezuela, Ecuador, Peru, and Panama, which use different naming schemes or sign colors/fonts.
