# Linear roadside colonia vs compact village-grid core settlement pattern

`atm_5b9c968b7ed1` · **culture** / region · cell `9exuvnc`

In rural Mexico, a village's historic compact grid core (dense housing around a central parish church) is often distinct from later linear 'colonia' growth strung out along an adjacent highway, with wide grassy setbacks, dispersed compounds, and unpaved side lanes. This settlement-pattern contrast lets analysts distinguish an older nucleated settlement from newer roadside sprawl sharing the same place name.
