# Interwar workers' housing blocks in Upper Silesian mining towns

`atm_736ac4eed284` · **architecture** / region · cell `u2vqqje`

Upper Silesian coal/steel towns feature dense 3-4 story interwar (1920s-30s) workers' apartment blocks with steeply pitched red-tile roofs, originally rendered/plastered, often adjacent to rail marshalling yards and coal stockpiles. Many have been recently retrofitted with EU-funded exterior insulation (styrofoam cladding, grey/red repainting), creating visual contrast with unrenovated neighboring blocks — a marker distinct from the red-brick 'familok' worker-terrace housing typical of nearby districts like Rozbark.
