# Nowa Huta: steel-town microdistrict planning in Poland

`atm_25a35da69a9d` · **history** / country · cell `u2yhzg5`

Nowa Huta, built from 1949 near Kraków around the Vladimir Lenin Steelworks, is a purpose-built socialist-realist industrial town organized into numbered residential districts with shared courtyards, schools, and green space, similar in function to Košice's Luník estates. It was designed partly as a demographic counterweight to Kraków's traditionally Catholic, intellectual population.
