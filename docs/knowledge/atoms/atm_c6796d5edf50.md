# Mono-cultural tourism economy: private housing converted to rental apartments

`atm_c6796d5edf50` · **economy** / polity · cell `srsfeq5`

In intensely tourism-dependent Adriatic coastal towns, private houses are commonly extended with external staircases, added balconies, and per-room split AC units to convert them into short-term rental apartments, visible as a dense, repetitive facade pattern. This is a marker of a near mono-cultural tourism economy overlaying an older stone fishing/villa-era urban fabric.
