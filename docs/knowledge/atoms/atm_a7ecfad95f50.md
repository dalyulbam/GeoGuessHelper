# Mexican state highway road-label prefixes encode the state

`atm_a7ecfad95f50` · **culture** / country · cell `9exuvnc`

Mexican state highways are commonly labelled with a two/three-letter state abbreviation prefix (e.g. GTO for Guanajuato, QRO for Querétaro, MICH for Michoacán, JAL for Jalisco) followed by the destination city. These prefixes, visible on road maps and highway signage, allow direct identification of the state a road segment lies in.
