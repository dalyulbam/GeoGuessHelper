# Flat terrain does not exclude the Cis-Urals

`atm_7291fe70d227` · **geography** / region · cell `v47mmjn`

The western Perm Krai and Vyatka lowlands are flat glacial-alluvial plain; you see level horizons, boggy grass and no rock outcrop, exactly as on the Upper Volga plain. Only in the eastern Perm Krai / Ural foothills would you instead see ridged skylines, road cuttings in bedrock and steeper river terraces. Flatness therefore removes only the Ural axis itself, not the entire Cis-Ural belt.
