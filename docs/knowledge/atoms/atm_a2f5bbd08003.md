# Elite summer-retreat suburbs later industrialized then residentialized

`atm_a2f5bbd08003` · **history** / global

Many historic port-city suburbs followed a similar three-stage arc: aristocratic summer villas, then 19th-20th century industrial/dockland use, then late-20th-century residential/service conversion. Examples include Naples' Posillipo, Istanbul's Bosphorus yalı villages, and Lisbon's Belém district, each shifting from noble leisure retreat to working district to modern mixed residential area.
