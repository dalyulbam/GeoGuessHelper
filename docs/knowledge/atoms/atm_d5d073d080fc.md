# Latvian rural-parish terminology and orthography

`atm_d5d073d080fc` · **language** / country · cell `ud4tpyy`

Latvia's rural municipal units are called 'pagasts' (parish), signed on boundary markers like 'X PAGASTS' on blue rectangular signs. Latvian uses Latin script with macrons and diacritics (ā, ē, ī, ū, ž, š) distinguishing it from Estonian ('vald' units, õ/ä diacritics) and Lithuanian ('seniūnija' units, -as/-ys endings with ė). Regional roads are numbered with a 'P' prefix (e.g., P38).
