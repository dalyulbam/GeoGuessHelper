# Ljetnikovac: Ragusan ashlar villa with arched quay doorway

`atm_020ef391a7c6` · **architecture** / region · cell `srsff7q`

Ragusan-era summer villas (ljetnikovci) along the Dubrovnik coast are typically built of finely dressed ashlar limestone with wrought-iron wall tie-anchors and arched doorways opening directly onto a stone quay, set within walled garden terraces and pergola courtyards. This building type is visually distinct from later Yugoslav-era concrete resort architecture, which instead shows slab-block hotels and wide promenades.
