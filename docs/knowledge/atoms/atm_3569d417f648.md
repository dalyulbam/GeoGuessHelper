# Bulgarian third-class road numbering system (треткласен път)

`atm_3569d417f648` · **geography** / country · cell `sx9wsps`

Bulgaria's road classification includes third-class (треткласен) routes marked with 4-digit numbers inside blue rectangular signage, where the leading digit(s) correlate with the oblast (province) the route belongs to — e.g., routes in Pleven oblast fall in a distinct numeric band from those in Ruse, Veliko Tarnovo, or Vratsa oblasts. This numbering pattern is a useful fine-grained discriminator for identifying the specific Bulgarian province from road signage alone.
