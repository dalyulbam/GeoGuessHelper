# Brick cascina with block shed is Lombard-to-Emilian, not diagnostic of Emilia

`atm_4ded08bf94f9` · **architecture** / region · cell `spyrs4k`

Flat-format brick with lime render, pantile roofs, a brick pillar gate and an attached grey breeze-block barn is the common lower-Po courtyard-farm build from Pavia and Lodi through Piacenza to Modena. In Tuscany or the Marche you would instead see rubble-stone or mixed stone-brick walls and steeper roofs, which is the real discrimination this typology supports. Using it to pick Parma over Pavia over-reads the cue.
