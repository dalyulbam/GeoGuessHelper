# Baltic and Nordic lowest-tier rural administrative units

`atm_a309cdfab8ce` · **language** / global

Across the Baltic and Nordic region, the lowest rural administrative tier carries distinct native names and naming logic: Latvian 'pagasts', Estonian 'vald', Lithuanian 'seniūnija', Finnish 'kunta', and Swedish 'socken' (historically parish-based, now largely replaced by 'kommun'). Each reflects a historical parish-to-municipality evolution parallel to the Latvian pattern.
