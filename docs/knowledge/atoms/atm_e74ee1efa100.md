# Peso magnitude with dot separators rules out dollarized Ecuador

`atm_e74ee1efa100` · **economy** / country · cell `d2g8r9w`

Colombian retail prices run to four or five digits with a dot as thousands separator and no cents, e.g. '$21.999'. In Ecuador (and Panama/El Salvador) you would instead see two-decimal USD prices like '$4.99', and in Peru an 'S/' prefix. Price magnitude alone separates the peso countries from the dollarized ones.
