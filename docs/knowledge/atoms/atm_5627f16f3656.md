# Pavillon lotissement kit is national, not regional — don't use it to narrow within France

`atm_5627f16f3656` · **architecture** / country · cell `u0g1ehg`

Beige/cream render, volet-roulant boxes, pierced-concrete claustra walls and clipped thuja hedges appear identically in Ardennes estates and in Eure-et-Loir estates. In a genuinely regional vernacular you would instead see load-bearing local material in older houses — flint/silex banding and half-timber in Normandy, red brick terraces in Hauts-de-France, chalk-limestone blocks in Champagne — so only pre-1950 buildings carry regional signal.
