# SA 0xx area codes on shop boards vs Botswana/Namibia national numbers

`atm_98d192cb04cf` · **language** / country · cell `k9fpcu8`

In South Africa, business signage carries a three-digit trunk code starting with 0 (041 for Nelson Mandela Bay, 011 Gauteng, 021 Western Cape) plus a seven-digit number, and mobiles start 082/083/072. In Botswana you would instead see eight-digit numbers with no area code and 7x mobiles, and in Namibia 061/064 codes with MTC branding. Reading the dialling code off a hardware or gas-depot board is often the fastest province-level lock in ZA.
